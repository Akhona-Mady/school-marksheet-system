# School Marksheet Automation System
React, Node.js, Express, MongoDB

Web app for teachers to capture marks, auto-calculate averages, flag at-risk learners, and export reports.

**Problem:** Teachers were calculating marks manually - slow and errors.
**Solution:** Central database + automated calculations + dashboard.

**Features:**
- Add learners
- Enter marks per subject
- Auto-calculate average & pass/fail
- Export report
